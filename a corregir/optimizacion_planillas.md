# Optimización de Planillas CSV y XLSX

## Sugerencias para CSV

1. **Estructura de archivos**:
   - Usar nombres descriptivos para los archivos CSV (ej. `datos_publicos_2026.csv`)
   - Mantener un solo archivo CSV por tipo de datos (evitar múltiples archivos para el mismo conjunto de datos)

2. **Contenido**:
   - Incluir encabezados claros y consistentes en todas las planillas
   - Usar comas como delimitador (formato estándar CSV)
   - Evitar caracteres especiales en los datos que puedan causar problemas

3. **Organización**:
   - Crear una carpeta dedicada para archivos CSV públicos
   - Mantener archivos privados en una carpeta separada

## Sugerencias para XLSX

1. **Estructura de archivos**:
   - Usar nombres descriptivos para los archivos XLSX (ej. `datos_publicos_2026.xlsx`)
   - Mantener un solo archivo XLSX por tipo de datos

2. **Contenido**:
   - Incluir hojas con nombres claros y consistentes
   - Usar formatos consistentes para fechas, números y texto
   - Limitar el uso de fórmulas complejas en las hojas públicas

3. **Organización**:
   - Crear una carpeta dedicada para archivos XLSX públicos
   - Mantener archivos privados en una carpeta separada

## Sugerencia para Gráficos

- Omitir la representación de la lista de puertas.linea por planeta en el gráfico compuesto ya que repite información ya presente en el gráfico de P1
